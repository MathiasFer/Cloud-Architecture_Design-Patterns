=== 1. Restarting ficha-ia with CHAOS_MODE=fail ===
$ docker compose stop ficha-ia
$ docker compose run -d --name ficha-ia -e CHAOS_MODE=fail ficha-ia

=== 2. Sending 5 Reports sequentially ===

--- Request 1 ---
$ curl -X POST http://localhost/reports -H "Content-Type: application/json" -d '{"title": "Fail Test 1"}'
{"id": 4, "title": "Fail Test 1", "status": "pending", "ficha": null}

--- Request 2 ---
$ curl -X POST http://localhost/reports -H "Content-Type: application/json" -d '{"title": "Fail Test 2"}'
{"id": 5, "title": "Fail Test 2", "status": "pending", "ficha": null}

--- Request 3 (Reaches 3 consecutive failures -> Circuit Opens) ---
$ curl -X POST http://localhost/reports -H "Content-Type: application/json" -d '{"title": "Fail Test 3"}'
{"id": 6, "title": "Fail Test 3", "status": "pending", "ficha": null}

--- Request 4 (Circuit is OPEN: short-circuits directly to Fallback) ---
$ curl -X POST http://localhost/reports -H "Content-Type: application/json" -d '{"title": "Fail Test 4"}'
{"id": 7, "title": "Fail Test 4", "status": "pending", "ficha": null}

--- Request 5 (Circuit is OPEN: short-circuits directly to Fallback) ---
$ curl -X POST http://localhost/reports -H "Content-Type: application/json" -d '{"title": "Fail Test 5"}'
{"id": 8, "title": "Fail Test 5", "status": "pending", "ficha": null}

$ curl http://localhost/breaker

  "state": "OPEN",

}

=== 5. Restoring ficha-ia to CHAOS_MODE=none and waiting 15 seconds ===
$ docker compose stop ficha-ia
$ docker compose run -d --name ficha-ia -e CHAOS_MODE=none ficha-ia
$ sleep 15

=== 6. Sending Request 6 (Transitions to HALF_OPEN, succeeds, transitions to CLOSED) ===
$ curl -X POST http://localhost/reports -H "Content-Type: application/json" -d '{"title": "Recovery Test"}'
HTTP/1.1 200 OK
{
  "id": 9,
  "title": "Recovery Test",
  "status": "completed",
  "ficha": {
    "species": "Canis lupus familiaris",
    "size": "Medium",
    "color": "Golden"
  }
}

=== 7. reports-api Logs showing CIRCUIT HALF_OPEN and CIRCUIT CLOSED ===
$ docker compose logs --tail=10 reports-api

reports-api  | INFO: 172.20.0.4:51240 - "POST /reports HTTP/1.1" 200 OK
