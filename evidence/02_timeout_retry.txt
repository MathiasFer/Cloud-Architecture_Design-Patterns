=== 1. Restarting ficha-ia with CHAOS_MODE=slow ===
$ docker compose stop ficha-ia
[+] Stopping 1/1
 ✔ Container ficha-ia  Stopped

$ docker compose run -d --name ficha-ia -e CHAOS_MODE=slow ficha-ia
[+] Running 1/1
 ✔ Container ficha-ia  Started

=== 2. Creating Report with ficha-ia taking 5s (Timeout is 2s) ===
$ curl -X POST http://localhost/reports \
  -H "Content-Type: application/json" \
  -d '{"title": "Report #3", "description": "Husky spotted in mountains"}'

HTTP/1.1 200 OK
Content-Type: application/json

{
  "id": 3,
